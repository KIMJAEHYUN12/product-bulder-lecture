> AI 기반 한국 주식 분석 플랫폼
> 작성일: 2026.03.23
> ※ 이 문서는 K-Startup 공식 HWP 양식에 옮겨 작성할 원본 콘텐츠입니다.

## 1. 문제인식 (Problem)

### 1-1. 창업아이템 배경 및 필요성

#### 한국 개인투자자의 정보 비대칭 문제

2024년 기준 한국 주식 투자 인구는 약 1,424만 명(한국예탁결제원, 2024.12)으로 경제활동인구의 약 50%에 달한다. 그러나 이 중 전문적 분석 도구를 활용하는 비율은 극히 낮다.

**핵심 문제 3가지:**

| 문제 | 현황 | 근거 |
|------|------|------|
| ① 분석 도구 접근성 | Bloomberg Terminal 연 $25,200, 증권사 HTS 설치형 PC 전용 | Bloomberg LP 공시가, 2025 |
| ② 데이터 해석 역량 | 개인투자자 64%가 "재무제표를 읽을 수 없다"고 응답 | 금융투자협회 투자자 실태조사, 2024 |
| ③ 감정적 투자 | 개인투자자 수익률이 기관 대비 연평균 -8.7%p 열위 | 한국거래소 투자자별 수익률 분석, 2023 |

#### PEST 분석

| 요인 | 내용 |
|------|------|
| **정치(P)** | 금융위원회 '디지털 금융혁신 계획'으로 핀테크 규제 완화 추진 중. 오픈뱅킹·마이데이터 확대 정책 |
| **경제(E)** | 고금리 장기화로 예적금 → 주식 이동 수요 지속. 2025년 금투세 폐지로 개인투자자 진입 장벽 하락 |
| **사회(S)** | MZ세대 투자 인구 급증 (20~30대 투자 인구 비율 2019년 18% → 2024년 37%). "돈 공부" 트렌드 |
| **기술(T)** | 생성형 AI(Gemini, Claude) 상용화로 자연어 기반 금융 분석이 기술적으로 가능해진 시점 |

#### 문제의 본질: "기관급 분석을 개인도 받을 수 있어야 한다"

기관투자자는 PER 밴드 분석, 수급 동향 추적, 회귀 채널 분석 등을 일상적으로 활용한다. 그러나 개인투자자가 동일한 분석을 수행하려면:
- Bloomberg Terminal 또는 FactSet 구독 필요 (연 2,500만원~)
- 엑셀/파이썬 프로그래밍 능력 필요
- 한국투자증권 등 HTS 설치 (PC 전용, 모바일 불가)

**SimplyStock은 이 격차를 AI로 해소한다.**

### 1-2. 목표시장 현황 분석

#### 시장 규모 (TAM → SAM → SOM)

```
TAM (전체 시장)
한국 온라인 투자정보 서비스 시장: 약 1조 2천억원 (2025)
├── 증권사 MTS/HTS: ~8,000억원
├── 유료 리서치 서비스: ~2,000억원
└── 핀테크 투자 분석 앱: ~2,000억원

SAM (유효 시장)
모바일 기반 주식 분석 서비스 시장: 약 2,000억원
├── 증권플러스 (두나무): ~800억원
├── 핀트/알파스퀘어 등: ~400억원
└── 신규 진입 가능 시장: ~800억원

SOM (초기 목표 시장)
AI 기반 무료 분석 → 프리미엄 전환: 약 30억원
├── 목표 MAU: 50,000명 (1년차)
├── 프리미엄 전환율: 3%
├── ARPU: 월 9,900원
└── 연 매출: 약 1,800만원 (1년차)
    + 광고 수익: 약 1,200만원
```

#### 경쟁사 분석

| 서비스 | 강점 | 약점 | SimplyStock 차별점 |
|--------|------|------|-------------------|
| **증권플러스** (두나무) | 대규모 사용자, 실시간 시세 | 분석 기능 부재, 단순 시세 조회 | AI 종합 분석 리포트 |
| **알파스퀘어** | 기술적 분석 도구 | 월 3.3만원 유료, PC 편향 | 모바일 우선, 핵심 기능 무료 |
| **TradingView** | 글로벌 차트 도구 | 한국 수급/공시 미지원, 영문 | 한국 시장 특화 (수급/DART) |
| **네이버 증권** | 트래픽 1위 | 분석 기능 없음, 뉴스 중심 | AI 분석 + 시각화 도구 |

**핵심 차별점: "한국 주식 시장에 특화된 AI 분석"을 무료로 제공하는 서비스가 없다.**

해외 사례 Finviz(미국)는 1인 개발자가 만든 무료 주식 스크리너로 월 2,050만 방문, 사이트 가치 $106M을 달성했다. Parqet(독일)은 독일어권 시장에만 집중하여 월 EUR 100K MRR을 달성했다. 두 사례 모두 "특정 시장 특화 + 무료 기본 + 프리미엄 전환" 모델이다.

## 2. 실현가능성 (Solution)

### 2-1. 창업아이템 현황 (MVP 개발 완료)

#### MVP 개발 완료 — 즉시 서비스 가능 상태

SimplyStock은 이미 **완전히 작동하는 MVP**가 개발되어 배포 중이다.

- **서비스 URL**: https://simplystock-b3b85.web.app
- **개발 기간**: 2025.09 ~ 2026.03 (약 6개월)
- **기술 스택**: Next.js 16 + TypeScript + Firebase + Gemini AI
- **앱 배포**: 웹(반응형) + Android APK (Capacitor)

#### 현재 구현된 핵심 기능 (11개)

| # | 기능 | 상태 | 설명 |
|---|------|------|------|
| 1 | **AI 종목 리포트** | ✅ 완료 | 기술·재무·수급 3축 분석 → S~D 등급 부여 |
| 2 | **PER 밴드 분석** | ✅ 완료 | 5년 역사적 PER 밴드 + Forward PER 포지션 |
| 3 | **시그널 스캐너** | ✅ 완료 | 수급 스캔 / 골든크로스 / 매수매도 신호 / 이력 검증 |
| 4 | **포트폴리오 건강검진** | ✅ 완료 | 스크린샷 OCR → 종목 인식 → AI 종합 분석 |
| 5 | **모의투자** | ✅ 완료 | 1,000만원 가상자금, 실시간 시세 반영 |
| 6 | **백테스트** | ✅ 완료 | 과거 데이터 기반 투자 시뮬레이션 (CAGR/샤프비율/최대낙폭) |
| 7 | **자본시장 대시보드** | ✅ 완료 | 공포탐욕지수, 채권, 환율, 프로그램매매, 공매도 종합 |
| 8 | **실적 캘린더** | ✅ 완료 | DART 공시 기반 실적 일정 |
| 9 | **투자성향 진단** | ✅ 완료 | 8유형 심리 테스트 → 맞춤 투자 전략 제안 |
| 10 | **관심종목** | ✅ 완료 | 최대 20종목, 실시간 가격 갱신 (1분 주기) |
| 11 | **투자 가이드** | ✅ 완료 | 12개 학습 콘텐츠 + 용어사전 5개 카테고리 |

#### AI 종목 리포트 — 핵심 차별 기능

```
[입력] 종목 심볼 (예: 005930 삼성전자)
  ↓
[수집] Yahoo Finance OHLCV + KIS API 수급 + DART 공시
  ↓
[분석] Gemini 2.5 Flash AI 엔진
  ├── 기술적 분석: RSI, MACD, 볼린저밴드, 거래량
  ├── 재무 분석: 매출 성장률, PER, ROE
  ├── 수급 분석: 외국인/기관 순매수 추세
  └── 밸류에이션: PER 밴드 포지션
  ↓
[출력] 종합 등급 (S/A/B/C/D) + 상세 리포트 + 점수 시각화
```

이 분석을 Bloomberg에서 받으려면 연 2,500만원, SimplyStock에서는 **무료**다.

#### 포트폴리오 건강검진 — 업계 유일 기능

```
[입력] 증권사 앱 잔고 스크린샷 촬영
  ↓
[OCR] 이미지에서 종목명·수량 자동 인식
  ↓
[수집] 종목별 PER 밴드 + 수급 동향 + 기술 지표 병렬 수집
  ↓
[분석] AI 포트폴리오 종합 진단
  ├── 분산도 점수 (0~100)
  ├── 섹터 집중도 경고
  ├── 종목간 상관관계 매트릭스
  └── AI 해석 코멘트
  ↓
[출력] 시각화 대시보드 (섹터 도넛 + 종목별 카드 + 분산도 점수)
```

**기존 서비스에서 이 기능을 제공하는 곳이 없다.** 증권사 앱은 단순 잔고 조회만 제공하며, AI 기반 포트폴리오 진단은 SimplyStock이 최초다.

## 3. 성장전략 (Scale-up)

### 3-1. 비즈니스 모델

#### 수익 모델 — 3단계 진화

```
[Phase 1: 트래픽 확보] 2026 하반기
├── 핵심 기능 100% 무료 제공
├── Google AdSense 광고 수익
├── 금융 제휴 광고 (증권사 가입, 투자 교육 CPA)
└── 목표: MAU 10,000명, 월 광고수익 50만원

[Phase 2: 프리미엄 전환] 2027
├── Pro 구독 출시 (월 9,900원 / 연 79,000원)
│   ├── 광고 제거
│   ├── AI 심화 분석 (종목 비교, 섹터 분석)
│   ├── 시그널 알림 (카카오톡/푸시)
│   └── PER 밴드 무제한 + 데이터 다운로드
├── 목표: MAU 50,000명, 유료 전환 3% = 1,500명
└── 월 매출: 1,485만원 + 광고 200만원 = 약 1,700만원

[Phase 3: B2B 확장] 2028~
├── 증권사/핀테크 API 데이터 라이선싱
├── 기업용 대시보드 (자산운용사, RIA)
├── 카카오톡 채널 AI 브리핑 구독
└── 목표: 월 매출 5,000만원+

| **최적화 과정** | 대량등록(양적 확장) → 반자동등록(효율화) → 수동등록(품질 집중)으로 3단계 피벗. 데이터 분석 기반으로 상품별 수익성을 추적하여 고마진 상품군에 집중하는 전략으로 전환 |
| **병행 실행력** | **4조 2교대 제조업 생산직 근무와 동시 병행**. 교대 근무 사이 시간을 활용하여 상품 리서치·등록·CS를 수행. 물리적으로 제한된 시간 안에서 최대 효율을 뽑아낸 경험 |

**이 경력이 SimplyStock에 직결되는 이유:**

```
쿠팡 경험                          SimplyStock 적용
─────────────────────────────────────────────────────
대량등록 → 수동등록 피벗           무료 기능 → 프리미엄 피벗 전략
  (양 → 질 최적화)                  (트래픽 → 수익화 전환)

상품별 수익성 데이터 분석          사용자 행동 데이터 분석
  (어떤 상품이 팔리는가)             (어떤 기능이 리텐션을 만드는가)

CS 운영 → 고객 니즈 파악           투자자 피드백 → 기능 우선순위
  (리뷰 분석 → 상품 개선)           (사용 패턴 → 제품 개선)

4조 2교대 중 사업 병행             1인 개발 + 운영 + 마케팅 병행
  (극한의 시간 관리)                (리소스 제약 하 실행력)
```

**핵심 메시지: "돈을 벌어본 사람"이 만드는 서비스다.**

대부분의 기술 창업자는 "좋은 제품을 만들면 사용자가 올 것"이라 생각한다. 그러나 대표자는 쿠팡에서 직접 상품을 팔아 연 1억 매출을 만들어본 경험이 있다. 수익화 구조를 설계하고 실행하는 것이 이론이 아니라 체화된 역량이다.

4조 2교대 생산직이라는 물리적 제약 속에서도 연매출 1억을 달성한 실행력은, 풀타임으로 SimplyStock에 집중할 경우 어떤 결과를 만들 수 있는지를 역으로 증명한다.

#### 개발 실적 — SimplyStock MVP 단독 완성

SimplyStock은 6개월간 1인이 다음을 완성했다:
- **프론트엔드**: 15개 페이지, 50+ 컴포넌트, 반응형 다크모드
- **백엔드**: 20+ API 엔드포인트, AI 분석 파이프라인, SSE 스트리밍
- **데이터**: Yahoo Finance, KIS API, DART 3개 데이터 소스 통합
- **배포**: Firebase Hosting + Android APK 빌드

이는 일반적으로 3~5인 팀이 12개월에 완성하는 규모다.

```
