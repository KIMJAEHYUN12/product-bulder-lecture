## Round 1: 기능의 핵심 가치 — "이게 왜 킬러 피처인가?"

**김애널 (금융):**
현재 개인투자자의 가장 큰 페인포인트를 정확히 짚은 기능입니다. 개인투자자는:

1. **보유종목은 있지만 분석 능력이 없다** — 매수는 했는데, 지금 이 포트폴리오가 괜찮은 건지 판단을 못 합니다. "삼성전자, SK하이닉스, 에코프로비엠" 이렇게 3개 들고 있는데, 이게 분산이 된 건지, 반도체+배터리에 올인한 건지 스스로 평가를 못 해요.

2. **정보가 흩어져 있다** — PER을 보려면 A사이트, 수급을 보려면 B사이트, 공시를 보려면 DART, 뉴스를 보려면 C사이트. 종합적으로 봐야 하는데 각각 따로 봐야 합니다.

3. **"이게 무슨 상황인지"를 모른다** — 데이터를 줘도 맥락을 읽지 못합니다. AI가 "반도체 섹터 65% 편중이고, SK하이닉스는 현재 PER 밴드 상단에 위치해 있으며, 에코프로비엠은 기관 순매도가 지속되고 있습니다"라고 현황을 정리해주면, 그게 진짜 가치입니다.

이 기능은 **"원스톱 포트폴리오 건강검진"**입니다. 사진 한 장이면 끝. 이건 기존에 없는 서비스예요.

**한비전 (프로덕트):**
현재 오비젼 빗각 사이트에도 비슷한 기능이 있지 않습니까? 포트폴리오 사진을 올리면 Gemini가 분석하는...

**김애널 (금융):**
핵심 차이가 있습니다. **현재 오비젼의 포폴 분석은 "이미지만 보고 AI가 추측"**하는 겁니다. Gemini가 스크린샷 속 종목명과 수량을 읽고, 자기가 가진 학습 데이터로 대충 판단하는 거예요. 실시간 데이터가 아닙니다.

제안하는 기능은 완전히 다릅니다:

### 현재 오비젼 vs 제안 기능 비교

| 항목 | 현재 오비젼 | 제안 기능 |
|------|-----------|-----------|
| 입력 | 스크린샷 이미지 | 스크린샷 이미지 (동일) |
| 종목 인식 | Gemini 비전 (OCR) | Gemini 비전 (OCR) → 종목코드 매핑 |
| 밸류에이션 | AI 추측 (부정확) | **PER 밴드 API 실제 조회** |
| 수급 | 없음 | **투자자 동향 API 실제 조회** |
| 차트 | 없음 | **일/주/월봉 추세선 실제 계산** |
| DART | 없음 | **최근 공시 실제 조회** |
| 뉴스 | 없음 | **관련 뉴스 실제 수집** |
| 분석 근거 | AI 일반 지식 | **실제 데이터 + AI 해석** |

**"추측"에서 "실데이터 기반 분석"으로의 질적 전환**입니다. 이건 무료 개인투자자 도구 시장에서 아무도 안 하고 있어요.

## Round 2: 법적 가이드라인 — "절대 해서는 안 되는 것"

**김애널 (금융):**
이 기능에서 **가장 중요한 원칙**을 먼저 세워야 합니다.

### 자본시장법 핵심 제약

자본시장법상 **투자 자문업 등록 없이 투자 판단을 제공하는 것은 불법**입니다. 이건 서비스의 존폐를 가를 수 있는 핵심 리스크입니다.

### 절대 하면 안 되는 것 vs 해도 되는 것

| 하면 안 되는 것 (투자 자문) | 해야 하는 것 (데이터 해석) |
|---------------------------|--------------------------|
| "삼성전자를 매수하세요" | "삼성전자는 외인이 15일 연속 순매수 중입니다" |
| "SK하이닉스 비중을 축소하세요" | "SK하이닉스는 PER 밴드 상단 78%에 위치해 있습니다" |
| "에코프로비엠을 손절하세요" | "에코프로비엠은 하락 추세가 지속되고 있으며, 기관 순매도가 20일째입니다" |
| "이 포트폴리오는 홀드하세요" | "반도체 섹터 비중이 65%로, 섹터 하락 시 전체 포트폴리오에 영향이 클 수 있습니다" |
| "20% 비중 조정을 권합니다" | "현재 포트폴리오의 상관계수가 0.82로 분산 효과가 제한적입니다" |

**핵심 원칙: "팩트와 해석만 제공, 행동 지시는 절대 금지"**

### AI 프롬프트에 반드시 포함할 제약 조건

```
[절대 규칙]
- "매수", "매도", "홀드", "손절", "비중 축소/확대", "추가 매수" 등
  투자 행동을 직접 지시하거나 권유하는 표현을 절대 사용하지 마세요.
- "~하세요", "~를 권합니다", "~해야 합니다" 같은 지시형 문장을 쓰지 마세요.
- 데이터 기반의 현황 분석과 상황 해석만 제공하세요.
- 투자 판단은 전적으로 사용자의 몫임을 명시하세요.
```

**한비전 (프로덕트):**
이 원칙을 리포트 출력에도 철저히 반영해야 합니다. 리포트의 성격 자체가 달라집니다:

| 기존 토론안 (문제 있음) | 수정안 (법적 안전) |
|----------------------|-------------------|
| "액션 플랜" 섹션 | "현황 요약" 섹션 |
| "종합 등급: B+" (투자 적합도 암시) | "분석 요약 스코어" (데이터 기반 건강도) |
| "홀드. 외인 수급 강함" | "외국인 15일 연속 순매수, PER 밴드 중앙" |
| "손절 검토" | "하락 추세 지속 중, 기관 매도 우위" |

**최수익 (그로스):**
"매수/매도" 지시가 없어도 가치가 충분합니까?

**김애널 (금융):**
오히려 더 가치 있습니다. 개인투자자가 진짜 원하는 건 "매수해" "매도해"가 아닙니다. 그런 건 주식 리딩방이 하는 건데, 리딩방 신뢰도가 바닥인 건 다 알아요.

투자자가 원하는 건 **"내가 스스로 판단할 수 있는 근거"**입니다:

- "아, 내가 반도체에 너무 몰려있구나" → 분산 필요성을 스스로 인지
- "아, 이 종목이 PER 밴드 상단이구나" → 고평가 가능성을 스스로 인지
- "아, 기관이 계속 팔고 있구나" → 수급 상황을 스스로 파악

**"물고기를 주지 말고 낚시하는 법을 알려줘라"**가 이 서비스의 정체성이어야 합니다. 그래야 재방문도 옵니다 — 매번 "이번엔 어떻게 변했지?" 확인하러 오니까요.

## Round 3: 기술 파이프라인 — "어떻게 만드는가?"

**정파이프 (기술):**
파이프라인을 단계별로 설계하겠습니다.

### Step 1: 이미지 OCR → 종목 리스트 추출
```
사용자 스크린샷 업로드
  ↓
Gemini Vision API (이미지 → 텍스트)
  ↓
JSON 추출: [
  { name: "삼성전자", qty: 10, avgPrice: 72000 },
  { name: "SK하이닉스", qty: 5, avgPrice: 180000 },
  { name: "에코프로비엠", qty: 3, avgPrice: 250000 }
]
  ↓
종목명 → 종목코드 매핑 (krStocks.json 또는 stockSearch API)
```

이 부분은 **현재 오비젼에 이미 구현되어 있습니다**. Gemini Vision으로 이미지에서 종목을 추출하는 건 검증된 기술입니다.

### Step 2: 종목별 데이터 병렬 수집
```
종목 코드 리스트 [005930, 000660, 247540]
  ↓ (Promise.allSettled — 병렬 호출)
┌─ fetchPerBand(symbol)         → PER/PBR 밴드 데이터
├─ fetchStockChart(symbol)      → OHLCV 차트 데이터
├─ fetchInvestorTrend(symbol)   → 외인/기관/개인 수급
├─ fetchDartFilings(symbol)     → 최근 DART 공시
├─ fetchStockNews(symbol)       → 관련 뉴스 (신규 개발)
└─ fetchStockReport(symbol)     → 기존 AI 리포트 (캐시 활용)
```

**핵심 포인트: 이 API들은 대부분 이미 존재합니다.**

| 데이터 | 기존 API | 상태 |
|--------|---------|------|
| PER 밴드 | `/api/per-band` | SimplyStock에 완성 |
| 차트 OHLCV | `/api/stock-chart` | 완성 |
| 수급 동향 | `/api/investor-trend` | 완성 |
| DART 공시 | 리포트 내 포함 | 완성 (개별 API 분리 필요) |
| 종목 뉴스 | 미구현 | **신규 개발 필요** |
| AI 리포트 | `/api/stock-report` | SimplyStock에 완성 |

**6개 데이터 소스 중 5개가 이미 있습니다.** 뉴스만 새로 만들면 됩니다.

### Step 3: 추세선 분석 (로컬 계산)
```
차트 OHLCV 데이터
  ↓
┌─ 단기 추세 (20일 이동평균 기울기)
├─ 중기 추세 (60일 이동평균 기울기)
├─ 장기 추세 (120일 이동평균 기울기)
├─ 회귀 채널 위치 (현재가 기준 %, 상단/하단)
├─ 골든크로스/데드크로스 여부
└─ RSI, MACD, 볼린저 밴드 상태
```

이것도 **SimplyStock의 bitgakEngine + signalScanner에 이미 계산 로직이 있습니다.**

### Step 4: AI 종합 해석 (LLM 호출)
```
수집된 전체 데이터를 구조화된 프롬프트로 조합
  ↓
LLM 호출 (Gemini 또는 Claude)
  ↓
SSE 스트리밍 응답
  ↓
종합 리포트 렌더링
```

**오모델 (AI):**
Step 4가 이 기능의 핵심입니다. 프롬프트 설계가 품질을 결정합니다.

## Round 5: LLM 선택 — Gemini vs Claude

**오모델 (AI):**
두 모델을 비교하겠습니다.

| 항목 | Gemini 2.5 Flash | Claude (Sonnet/Haiku) |
|------|-----------------|----------------------|
| 비용 | 무료 티어 충분 (RPM 제한 있음) | 유료 ($3~15/1M tokens) |
| 이미지 OCR | 우수 (Vision 내장) | 우수 (Vision 내장) |
| 긴 컨텍스트 | 1M 토큰 | 200K 토큰 |
| 금융 분석 품질 | 보통~양호 | 양호~우수 |
| 한국어 | 양호 | 우수 |
| 구조화 출력 | 양호 | 우수 (JSON 모드 강함) |
| **지시 준수 (투자조언 금지 등)** | 보통 | **우수 (안전 가드레일 강함)** |
| 스트리밍 | 지원 | 지원 |

**제 추천은 "하이브리드"입니다:**

```
Step 1 (이미지 OCR): Gemini Vision — 무료, 이미지 인식 우수
Step 4 (종합 해석): Gemini 2.5 Flash — 무료 티어로 충분
                    또는 Claude Haiku — 지시 준수력이 높아 "투자 조언 금지" 규칙 위반 가능성 낮음
```

특히 **"투자 조언 금지" 규칙 준수**가 중요한데, Claude 계열이 이런 제약 조건을 더 잘 지킵니다. Gemini는 가끔 "~하는 것이 좋겠습니다" 같은 표현이 나올 수 있어서 후처리 필터링이 필요할 수 있습니다.

현재 오비젼이 이미 Gemini 2.5 Flash를 쓰고 있으니, **추가 비용 없이 Gemini로 시작**하되 프롬프트에 금지 표현을 강하게 명시하고, 필요시 Claude로 전환하는 게 합리적입니다.

## Round 6: 데이터 수집 시간과 UX

**정파이프 (기술):**
기술적 챌린지가 있습니다. **데이터 수집 시간**입니다.

종목 5개를 분석한다고 하면:

| 데이터 | 종목당 소요 |
|--------|-----------|
| PER 밴드 | 2~5초 (DART 조회 포함) |
| 차트 데이터 | 1~2초 |
| 수급 데이터 | 2~3초 |
| DART 공시 | 1~2초 |
| 뉴스 | 1~3초 |

**병렬 처리해도 종목당 3~5초, 5종목이면 15~25초**. 여기에 LLM 해석이 5~15초 추가.

총 사용자 대기시간: **20~40초**.

이건 긴 편이지만, **프로그레스 UI로 해결 가능**합니다:

```
[1/5] 삼성전자 데이터 수집중... ✓
[2/5] SK하이닉스 데이터 수집중... ✓
[3/5] 에코프로비엠 데이터 수집중...
──────────────────────────
AI가 데이터를 해석하고 있습니다...
```

이 "살아있는 프로그레스"가 오히려 **신뢰감을 줍니다**. "진짜 데이터를 수집하고 있구나"라는 느낌.

### 타임아웃 해결 아키텍처

```
[Frontend]                      [Backend]
사진 업로드 ─POST──→ /api/portfolio-analyze
                     ├─ Step 1: Gemini OCR (3초)
                     ├─ 종목 리스트 응답 (SSE: 종목 인식 완료)
                     ├─ Step 2: 데이터 수집 (15초, 병렬)
                     ├─ 진행 상황 SSE 전송
                     ├─ Step 3: LLM 해석 (10초)
                     └─ 결과 SSE 스트리밍
```

**전체를 하나의 SSE 스트림으로 처리**하면, 프론트에서 단계별 프로그레스를 실시간으로 표시할 수 있고, 사용자는 40초를 "기다리는" 게 아니라 "과정을 지켜보는" 경험을 합니다.

## Round 10: 수익화와 바이럴 전략

**최수익 (그로스):**

### 무료/유료 분기

| 기능 | 무료 | 프리미엄 |
|------|------|----------|
| 일일 분석 횟수 | 1~2회 | 무제한 |
| 종목 수 | 최대 5종목 | 최대 20종목 |
| 데이터 깊이 | 기본 (PER + 수급 + 추세) | 전체 (+ DART + 뉴스 + 상관분석) |
| 리포트 저장 | 없음 | 히스토리 30일 |
| 내보내기 | 없음 | PDF/이미지 |

### 바이럴 설계

**이 기능은 본질적으로 바이럴합니다.** 왜?

1. **결과물이 공유 가능** — "내 포트폴리오 분산도 점수가 35점이래ㅋㅋ" → 카카오톡 공유
2. **비교 욕구 자극** — "너는 몇 점?" → 친구에게 추천
3. **반복 사용** — 매매할 때마다 다시 분석 (종목 변동)

중요: 공유 콘텐츠에도 **"매수/매도" 표현이 없어야** 합니다. "분산도 35점, 반도체 편중 65%" 같은 팩트 기반 숫자가 공유 포인트가 됩니다.

**공유 게이트 (SimplyStock의 밸류에이션에 이미 적용됨):**
- 첫 1회 분석 무료
- 추가 분석하려면 결과를 SNS 공유
- 공유 시 당일 무제한

| 2 | **데이터 수집 실패** — 5개 API 중 1개 실패 | `Promise.allSettled`, 실패 항목 "데이터 없음" 표시 |
| 3 | **AI가 투자 조언을 출력** — 프롬프트 무시 가능성 | 후처리 필터링 + 금지 키워드 차단 + Claude 전환 검토 |
| 4 | **법적 리스크** — 해석도 조언으로 해석 가능 | 면책 고지 필수, 리포트 상/하단 삽입 |
| 5 | **Firebase Functions 타임아웃** — 5종목 = 40초+ | `timeoutSeconds: 120`, SSE 2단계 분리 |

### AI 출력 후처리 필터링 (안전장치)

```javascript
const BANNED_PATTERNS = [
  /매수.*하세요/g,
  /매도.*하세요/g,
  /손절/g,
  /비중.*축소/g,
  /비중.*확대/g,
  /추가.*매수/g,
  /홀드/g,
  /~를 권합니다/g,
  /~해야 합니다/g,
];

function sanitizeAdvice(text) {
  let safe = text;
  for (const pattern of BANNED_PATTERNS) {
    safe = safe.replace(pattern, '[데이터를 참고하여 직접 판단해주세요]');
  }
  return safe;
}
```

이 후처리를 거치면 AI가 실수로 투자 조언을 출력해도 사용자에게 전달되지 않습니다.

# 추가 토론: "AI 결과물의 신뢰 차별화" — ChatGPT와 뭐가 다른데?

> 날짜: 2026-03-22 (연속 세션)
> 안건: 실데이터 기반 분석을 만들어도, 사용자 눈에는 "그냥 AI가 뱉은 글"로 보이는 문제 해결
> 배경: 대부분의 사용자가 주식 초보 → 가이드/블로그를 써도 이해 못 함 → 데이터 품질 차이를 인지 못 함

---

## 문제 정의

> **사용자가 실데이터 기반 분석 결과를 "그냥 ChatGPT한테 물어본 거랑 뭐가 다른데?"라고 느끼는 문제.**
>
> 아무리 백엔드에서 PER 밴드, 수급, 차트, DART를 실제 조회해도, 최종 출력이 "AI가 쓴 텍스트"로 보이면 차별점이 전달되지 않는다.
>
> 추가로, 주식 초보 사용자는 데이터를 줘도 무슨 의미인지 모르기 때문에 기존 사이트 기능(가이드, 블로그)으로는 리텐션이 안 나온다.

---

## Round 1: 문제의 본질 — "왜 같아 보이는가?"

**한비전 (프로덕트):**
근본 원인을 분석하겠습니다. 사용자가 "ChatGPT랑 똑같네"라고 느끼는 이유는 3가지입니다:

**1. 출력 형태가 동일하다**
ChatGPT에게 "삼성전자 분석해줘"라고 하면 텍스트 덩어리가 나옵니다. 우리 서비스도 텍스트 덩어리가 나옵니다. 사용자 눈에는 **같은 포맷**입니다.

**2. "데이터 출처"가 보이지 않는다**
우리가 PER 밴드 API를 호출하든, AI가 학습 데이터에서 추측하든, 최종 텍스트에 "PER 12.5배"라고 쓰여 있으면 사용자는 **이 숫자가 실시간인지 AI 추측인지 구분 못 합니다**.

**3. 주식 초보는 "좋은 분석"과 "나쁜 분석"을 구분 못 한다**
경험 있는 투자자는 "이 수급 해석이 정확하네"를 알지만, 초보는 글이 그럴듯하면 다 비슷해 보입니다. **품질 차이를 인지할 역량이 없습니다.**

**김애널 (금융):**
정확합니다. 이건 **"정보 비대칭의 역설"**입니다. 우리가 더 정확한 데이터를 쓸수록, 사용자는 그 차이를 덜 느낍니다. 왜? 정확한 데이터가 뭔지 모르니까.

증권사 리서치 보고서도 같은 문제를 겪습니다. 일반인은 삼성증권 보고서와 GPT 출력을 구분 못 해요. 차이를 만드는 건 **"보고서의 내용"이 아니라 "보고서의 형식과 증거"**입니다.

## Round 2: 해법 — "데이터가 실제라는 것을 눈에 보여줘라"

**한비전 (프로덕트):**
핵심 전략은 **"데이터 프로비넌스(출처)를 시각적으로 드러내는 것"**입니다. AI 텍스트와 실데이터를 분리 배치합니다.

맞습니다. 이건 **"극장 효과(Theatre Effect)"**라고 합니다. 보안 앱이 "바이러스 검사 중... 1,234개 파일 스캔"을 보여주는 것과 같은 원리입니다.

우리는 실제로 시간이 걸리니까 가짜가 아닙니다. **진짜 과정을 투명하게 보여주는 것**입니다.

**오모델 (AI):**
한 단계 더 나가서, **수집 완료된 데이터를 프로그레스 중에 미리 보여주면** 더 좋습니다.

```
✓ 삼성전자 PER 밴드 조회 완료
  → 현재 PER 12.5배 (밴드 중앙 52%)  ← 즉시 표시
```

데이터가 하나씩 도착할 때마다 화면에 숫자가 채워지는 경험. **"AI가 글을 쓰는 게 아니라, 실제 데이터가 모이고 있구나"**라는 인식을 줍니다.

## Round 4: "숫자에 의미를 입혀줘라" — 초보 교육 내장

**오모델 (AI):**
주식 초보가 데이터를 봐도 모른다는 문제는, **"숫자 옆에 한 줄 해석"을 붙이는 것**으로 해결합니다.

### Before (초보가 이해 못 함)
```
PER: 12.5배
RSI(14): 62
외국인 순매수: +4,200억
```

### After (초보도 이해)
```
PER: 12.5배
  └ 과거 10년 기준 "중간 정도" 가격입니다

RSI(14): 62
  └ 과열도 과냉도 아닌 "보통" 상태입니다

외국인 순매수: +4,200억 (15일 연속)
  └ 외국인이 꾸준히 사들이고 있습니다
```

**이 "한 줄 해석"은 AI가 아니라 규칙 기반으로 생성합니다:**

```javascript
function interpretPER(per, bandPosition) {
  if (bandPosition > 80) return '과거 10년 기준 "비싼 편"입니다';
  if (bandPosition > 60) return '과거 10년 기준 "약간 비싼" 수준입니다';
  if (bandPosition > 40) return '과거 10년 기준 "중간 정도" 가격입니다';
  if (bandPosition > 20) return '과거 10년 기준 "저렴한 편"입니다';
  return '과거 10년 기준 "매우 저렴한" 구간입니다';
}

function interpretRSI(rsi) {
  if (rsi > 70) return '과열 신호가 감지됩니다';
  if (rsi > 60) return '약간 뜨거운 상태입니다';
  if (rsi > 40) return '과열도 과냉도 아닌 "보통" 상태입니다';
  if (rsi > 30) return '약간 차가운 상태입니다';
  return '과매도 신호가 감지됩니다';
}

function interpretForeignBuy(amount, consecutiveDays) {
  if (amount > 0 && consecutiveDays >= 10)
    return '외국인이 꾸준히 사들이고 있습니다';
  if (amount > 0 && consecutiveDays >= 5)
    return '외국인 매수세가 이어지고 있습니다';
  if (amount > 0)
    return '외국인이 최근 순매수로 전환했습니다';
  if (amount < 0 && consecutiveDays >= 10)
    return '외국인이 지속적으로 팔고 있습니다';
  return '외국인 매도세가 관찰됩니다';
}
```

**이 방식의 장점:**
1. **AI 환각 없음** — 규칙 기반이라 틀릴 수 없음
2. **초보 교육 효과** — "PER이 뭔지 몰라도, '중간 정도 가격'이면 이해함"
3. **ChatGPT와 차별화** — ChatGPT는 이런 맥락화된 해석을 실데이터 기반으로 못 함
4. **일관성** — 매번 같은 기준으로 해석, 신뢰 축적

**김애널 (금융):**
이거 아주 중요합니다. 증권사 보고서가 읽기 어려운 이유가 **전문 용어를 설명 없이 쓰기 때문**입니다. "RSI 62"를 보고 뭔 뜻인지 아는 개인투자자가 몇이나 될까요?

**"초보를 위한 통역"이 내장된 분석 도구** — 이게 SimplyStock의 정체성이 되어야 합니다. 전문가용 도구가 아니라, **초보가 전문가 수준의 데이터를 이해할 수 있게 해주는 도구**.

## Round 5: "ChatGPT가 못 하는 형태"로 결과물 구성

**김애널 (금융):**
ChatGPT와 가장 확실하게 차별화되는 건 **"ChatGPT가 절대 못 만드는 형태"**로 결과를 주는 겁니다.

### ChatGPT가 못 하는 것들

| # | 기능 | ChatGPT | SimplyStock |
|---|------|---------|-------------|
| 1 | 실시간 미니 차트 | 불가 | 20일 스파크라인 |
| 2 | PER 밴드 게이지 | 불가 | 10년 밴드 위 현재 위치 시각화 |
| 3 | 수급 바 차트 | 불가 | 30일 외인/기관/개인 바 |
| 4 | DART 원문 링크 | 불가 | 클릭 → 실제 DART 페이지 이동 |
| 5 | 포트폴리오 상관관계 히트맵 | 불가 | 종목 간 상관계수 시각화 |
| 6 | 데이터 신선도 타임스탬프 | "2024년 기준" | "2분 전 업데이트" |

**이런 시각 요소가 있으면 사용자는 절대 "ChatGPT랑 같다"고 생각하지 않습니다.** ChatGPT는 실시간 차트를 그릴 수 없으니까요.

**정파이프 (기술):**
기술적으로 이 시각 요소들은 **이미 SimplyStock에 구현되어 있습니다**:

| 시각 요소 | 기존 구현 위치 | 재활용 가능성 |
|----------|--------------|-------------|
| PER 밴드 차트 | `/valuation/` 페이지 | 미니 버전으로 축소 |
| 수급 바 차트 | 메인 SignalScanner | 컴포넌트 추출 |
| 스파크라인 차트 | 관심종목 사이드바 | 그대로 사용 |
| DART 링크 | AI 리포트 (`/report/`) | 그대로 사용 |
| 레이더 차트 | 기존 오비젼 AnalysisReport | 그대로 사용 |

새로 만들어야 할 건 **상관관계 매트릭스** 정도입니다. 나머지는 기존 컴포넌트를 조합하면 됩니다.

## Round 6: 인터랙티브 + 딥링크 — "만져볼 수 있는 데이터"

**한비전 (프로덕트):**
ChatGPT 출력은 **읽기만** 합니다. 우리 서비스는 **만져볼 수 있고, 더 깊이 들어갈 수 있습니다**.

### 인터랙티브 차별화 포인트

**1. 종목 클릭 → SimplyStock 상세 페이지 연결**
```
삼성전자 (005930)  [상세 분석 보기 →]  [밸류에이션 →]
```
리포트에서 종목을 클릭하면 `/stock/005930/` 또는 `/valuation/?ticker=005930`으로 이동. 더 깊은 분석이 가능합니다.

이건 **SimplyStock 내에서 구현할 때의 최대 장점**입니다. 포폴 분석 → 종목 상세 → 밸류에이션 → 수급 차트로 자연스럽게 이어지는 여정.

**2. "이 종목과 같은 섹터" 비교 (데이터 기반)**
```
에코프로비엠과 같은 배터리 섹터:
  LG에너지솔루션 — PER 하단 18%, 추세 ↓↓→
  삼성SDI — PER 중앙 45%, 추세 →→↑
```
→ "같은 섹터 내에서 비교"가 가능. ChatGPT는 실시간 비교 데이터가 없습니다.

## Round 7: "전후 비교" — 리텐션 극대화

**최수익 (그로스):**
초보 사용자가 재방문하게 만드는 가장 강력한 기능은 **"지난번과 비교"**입니다.

### 포트폴리오 변화 추적

```
┌─ 지난 분석 (03/15) vs 이번 분석 (03/22) ────┐
│                                              │
│  삼성전자                                    │
│  PER 위치: 48% → 52% (▲4%p)                 │
│  수급: 외인 +3,100억 → +4,200억 (▲강화)      │
│  추세: 단기↑중기→ → 단기↑중기↑ (▲개선)        │
│                                              │
│  에코프로비엠                                │
│  PER 위치: 15% → 12% (▼3%p)                 │
│  수급: 기관 매도 15일 → 20일 (▼악화)          │
│  추세: 변화 없음 (↓↓↓)                       │
│                                              │
│  포트폴리오 분산도: 32점 → 35점 (▲소폭 개선)  │
│                                              │
└──────────────────────────────────────────────┘
```

**이건 ChatGPT가 절대 못 합니다.** ChatGPT는 이전 대화를 기억하지 못하거나, 기억해도 실시간 데이터 비교는 불가능합니다.

"지난주에 비해 외국인 매수가 강해졌네?" — 이 한 줄이 사용자를 **매주 재방문**하게 만듭니다.

**한비전 (프로덕트):**
이걸 위해서는 **분석 히스토리를 저장**해야 합니다. 로그인 사용자는 Firestore에, 비로그인은 localStorage에. SimplyStock의 기존 패턴(관심종목 — 로그인 시 Firestore, 비로그인 시 localStorage)을 그대로 따르면 됩니다.

## Round 8: 신뢰 배지 + 데이터 신선도

**최수익 (그로스):**
**"이 데이터가 실제임을 증명하는 시각적 장치"**가 필요합니다.

### 데이터 출처 배지

각 데이터 항목 옆에 출처 배지를 붙입니다:

```
[DART] PER 12.5배 (밴드 중앙 52%)
[KIS]  외인 +4,200억 (15일 연속)
[Yahoo] 단기 추세 ↑ (+0.3%/일)
[DART] 분기보고서 (2026-03-15) → 원문 보기
```

- `[DART]` — 금융감독원 전자공시시스템
- `[KIS]` — 한국투자증권 API
- `[Yahoo]` — Yahoo Finance

**사용자가 "원문 보기"를 클릭하면 실제 DART 공시 페이지로 이동**합니다. 이 하나의 기능만으로 "이건 AI가 지어낸 게 아니다"를 증명합니다.

### 데이터 신선도 표시

```
📊 데이터 기준: 2026.03.22 15:30 (장 마감 후)
마지막 업데이트: 2분 전
```

ChatGPT는 "2024년 데이터 기준"이라고 말하거나 아예 말을 안 합니다. 우리는 **"2분 전 데이터"**라고 말할 수 있습니다. 이 차이가 신뢰입니다.

## 핵심 결론

> **핵심 문제:** 사용자는 "AI가 쓴 텍스트"를 보면 출처가 뭐든 다 같아 보인다.
>
> **해법: 텍스트를 줄이고 데이터를 보여줘라.**
>
> 1. 결과물의 70%는 **시각 데이터** (차트, 게이지, 바, 테이블), 30%만 AI 해석 텍스트
> 2. 모든 데이터에 **출처 배지와 타임스탬프** 부착 → "이건 실제 데이터"임을 증명
> 3. 모든 지표에 **초보 해석 한 줄** 부착 (규칙 기반, AI 아님) → 전문 용어 장벽 제거
> 4. 데이터 수집 과정을 **투명하게 보여주기** → 20~40초가 신뢰 구축 시간으로 전환
> 5. **전후 비교** 기능으로 재방문 동기 부여 → 리텐션 해결
>
> **"ChatGPT는 글을 쓰고, SimplyStock은 데이터를 보여준다"** — 이게 포지셔닝이다.
