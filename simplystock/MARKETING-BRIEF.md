# SimplyStock 서비스 브리핑

## 서비스 개요
- **이름**: SimplyStock (심플리스톡)
- **URL**: https://www.simplystock.co.kr
- **한줄 소개**: 데이터 기반 주식 차트 분석 + 투자 학습 + 모의투자 통합 플랫폼
- **타겟**: 주식 초급~중급 개인투자자, 기술적 분석 학습자
- **가격**: 무료 (광고 수익 모델, Google AdSense)
- **기술**: Next.js 16 + Firebase + Lightweight Charts

---

## 핵심 기능 (7가지)

### 1. 차트 분석 (메인 페이지)
- 종목 검색 → 10년치 캔들 차트 즉시 로드
- **회귀 채널**: 7선 이동평균 기반으로 주가의 "정상 범위"를 시각화
- **투자자 수급 흐름**: 외국인/기관/개인 매매 동향을 차트 위에 오버레이
- 타임머신: 과거 시점 선택하여 그 때의 지표 재계산
- 풀스크린 차트 모드 (모바일 최적화)

### 2. 종목 스캐너 (실시간 신호)
- **수급 반전 스캔**: 외인+기관 3일 연속 매수 전환 종목 자동 감지
- **골든크로스 스캔**: 5/20일, 20/60일 이동평균 교차 + 수급 필터
- 전일 마감 기준 자동 갱신
- 골든크로스 성적표: 과거 신호의 실제 수익률 통계

### 3. 밸류에이션 (PER 밴드)
- DART 공시 기반 10년 EPS 추이
- PER/PBR 밴드 차트: 현재 주가가 역사적으로 비싼지 싼지 판단
- 저평가/적정/고평가 5단계 구간 표시
- Forward PER (Yahoo Finance)

### 4. 모의투자
- 초기 자본 1,000만원, Google 로그인 필수
- 실시간 시세 기반 매매 체결
- 포트폴리오 손익률 추적
- 사용자 간 랭킹 보드 + AI 봇 비교
- 성적표 이미지 생성 + 카카오톡 공유

### 5. 투자성향 테스트
- 20문항 → 8가지 투자자 유형 도출
- 유형별 강점, 주의사항, 어울리는 자산 안내
- 결과 이미지 생성 + 카카오톡 공유 (바이럴 요소)

### 6. 종목 분석 페이지 (50개 대표 종목)
- /stock/005930/ (삼성전자) 등 SEO용 정적 페이지
- 회귀채널 상태 + PER 밴드 + 수급 동향 + 골든크로스 신호
- Google 검색 유입 타겟

### 7. 학습 콘텐츠
- **가이드 8편**: 회귀채널, 수급분석, PER밴드, 수급스캔, 백테스트, 모의투자 등
- **용어사전**: 차트, 기술적 분석, 밸류에이션, 주문 종류 등 카테고리별 정리
- **분석 자료실**: 회귀 언더밸류 종목 리스트, 수급 교차점 분석

## 부가 기능
- **관심종목 (Watchlist)**: 최대 20개, 로그인 시 클라우드 동기화
- **원자재 시세**: 금/은/유가/농산물/금속 시세
- **실적 캘린더**: 상장사 분기별 실적 공시 일정
- **뉴스 티커**: 실시간 경제 뉴스

## 데이터 소스
| 데이터 | 소스 | 신뢰도 |
|--------|------|--------|
| 차트 (OHLCV) | Yahoo Finance | 높음 |
| 투자자 수급 | KIS API (한국투자증권) | 높음 (공식 거래소) |
| PER/EPS | DART (금융감독원 공시) | 매우 높음 |
| 현재가 | Yahoo Finance | 높음 |

---

## 차별화 포인트
1. **통합 플랫폼**: 분석 + 학습 + 실습을 한 곳에서 (네이버금융은 분석만, 증권앱은 거래만)
2. **회귀 채널**: TradingView에는 있지만 한국 개인투자자용 무료 서비스는 거의 없음
3. **수급 + 차트 결합**: 외국인/기관 매매를 차트 위에 직접 표시
4. **PER 밴드**: DART 공시 기반으로 10년 역사적 밸류에이션 제공
5. **진입 장벽 없음**: 무료, 회원가입 선택, 검색만으로 즉시 분석 가능
6. **한국 시장 특화**: 한국 종목 + 한국어 + DART/KIS 데이터

## 사용자 여정
```
검색 유입 → 차트 분석 체험 → 가이드로 학습 → 모의투자 가입
→ 랭킹 경쟁 → 성적 공유 → 친구 유입 (바이럴 루프)
```

## 해결하는 문제
| 투자자의 고민 | SimplyStock 솔루션 |
|--------------|-------------------|
| 차트가 복잡하고 해석 어려움 | 회귀채널로 "정상 범위" 한눈에 파악 |
| 기관/외국인이 뭘 사는지 모름 | 수급 흐름 차트 + 실시간 스캔 |
| 이 종목이 비싼지 싼지 모름 | PER 밴드로 10년 역사 대비 위치 확인 |
| 실전 경험 없이 투자 시작 두려움 | 모의투자로 리스크 없이 연습 |
| 기술적 분석 용어가 어려움 | 가이드 + 용어사전으로 쉽게 학습 |
